# dis-macununun-ortadan-sikilmasi-hazine-ve-maliye-bakanligi
Diş macununun tüpün ortasından sıkılmasını resmi mali disiplin ihlali, milli macun rezervi israfı ve hazine kaybı sayan; kapağı vezne, tüpü bütçe, 'biraz daha sıkınca çıkar' cümlesini ödenek talebi ilan eden Bakanlık. Gerçekten çalışır. Macunlar artık ödenektir.
