# T.C. Hazine ve Maliye Bakanlığı
## Diş Macunu Rezervi ve Tüp Disiplini Genel Müdürlüğü

### `dis-macununun-ortadan-sikilmasi-hazine-ve-maliye-bakanligi`

Bu depo, maliyenin en eski israf kalemini kayda geçirir: **diş macununun tüpün ortasından sıkılması.**

Vatandaş bunu alışkanlık dedi. Eş bunu ihanet sandı. Tüp bunu bütçe sandı. Konu artık hazinedir.

---

## Resmi Görev Tanımı

Müdürlük şunları resmi kayıt sayar:

- Kapak, veznedir.
- Tüp, yıllık bütçedir.
- Orta kısım, kayıt dışı harcamadır.
- Uç kısım, planlı ödenektir.
- Dip kısım, gelecek nesildir.
- “Biraz daha sıkınca çıkar” cümlesi, ek ödenek talebidir.
- Fırça, harcama birimidir.

Macunlar artık ödenektir. Bu cümle şaka değildir. Şaka olarak yazılmıştır. İkisi birden.

---

## Kuruluş Gerekçesi (Aşırı Ciddi)

1. Vatandaş tüpü aldı.
2. Kapağı açtı.
3. Ucu değil ortayı sıktı.
4. Rezerv eğrisi çöktü.
5. Dipte kalan millete kaldı.
6. Tarih durdu.
7. Bu depo açıldı.

---

## Çalıştırma

Python 3.10+ yeter. Bağımlılık yoktur. Maliye sade tutulmuştur.

```bash
python3 macun_butcesi.py
```

Çıktı bir hazine tutanağıdır:

- tüp envanteri
- sıkma noktası denetimi
- rezerv kaybı hesabı
- vezne bildirimi
- hüküm
- muhalefet şerhi
- damga, imza, tarih
